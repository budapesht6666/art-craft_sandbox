# Craft-программы и remotion-skill

Проект `C:\projects\claude\remotion-skill` делает вертикальные Shorts на Remotion 4 с
помощью Claude Code. Эффекты там уже делаются кодом: Remotion, Pixi, Three.js, ffmpeg,
potrace, sharp. Поэтому Craft-программы проект не заменят. Они полезны там, где
визуально или руками удобнее, чем кодом.

Ничего из этого пока не проверено на деле.

## По убыванию пользы

### 1. EffectCraft: анимированные элементы

- Claude собирает анимацию в EffectCraft через MCP (или вы руками, как в After Effects):
  заставку, плашку, переход.
- Экспорт в **Lottie**. Remotion вставляет его через `@remotion/lottie`, в проекте этот
  пакет пока не стоит. Скилл `remotion-markup/lottie.md` уже есть.
- Или экспорт в видео с прозрачностью (ProRes 4444, WebM VP9) и наложение через `<Video>`.
- Пример: одна фирменная плашка «подпишись» для всех Shorts.
- **Первая проба:** Lottie-плашка в композиции `KineticText`.

### 2. spark: фотореалистичные 3D-сцены для `/remotion-3d`

- Gaussian splats в Three.js, ставится через npm, лицензия MIT.
- Пролёт камеры по реальной комнате или улице, чего на примитивах не сделать.
- Риски: тяжело для встроенной графики. Сортировка splat-ов в spark идёт асинхронно,
  поэтому при покадровом рендере возможны мерцание и разные кадры. Нужен тест.

### 3. ArtCraft: кадры в одном стиле для `DiverBotAd` (платно)

- В `scripts/gen-refs.ts` описана та же проблема: пять планов выходят «пятью разными
  фильмами».
- ArtCraft держит одинаковыми локацию и персонажа и даёт расставить сцену в 3D.
- Минусы: кредиты, официального API или MCP нет. Только вручную: сгенерировали, положили
  в `public/assets/.../refs/`.

### 4. PhotoCraft и LightCraft: подготовка стока

- Через MCP или CLI привести фото из Unsplash и Pexels к одному цвету и экспозиции.
- Вырезать объект (SAM 3 в LightCraft).
- Польза умеренная: то же самое делается через `sharp` или ffmpeg, которые уже есть.

### 5. VectorCraft: чистка контуров для `/whiteboard`

- Поправить мусор после potrace в SVG.
- Пригодится редко.

## Не стоит брать

- **FilmCraft** — дублирует то, что уже делают Remotion и ffmpeg (`series-cut`,
  `film-remix`). Разве что смотреть и поправлять нарезку руками через FCP XML.
- **Офисные программы** — к видео отношения не имеют.
