# Голос для шота «DON'T LOOK.»

Записывает пользователь (телефон, «Диктофон» в режиме «Без сжатия»). Файл класть сюда как
`dont_look_take1.m4a`. Под голос шот перестраивается: ~14 с вместо 6.

```
So Perseus now owned the deadliest weapon in Greece:
a head that turned anyone who looked at it into stone.

The instructions were simple.

(пауза)

Don't look.

(пауза: крик и хруст камня)

The guards... did not read the instructions.
```

Произношение: Perseus — «ПЁР-си-ус», Medusa — «ме-ДУ-са», Greece — «гриис».
