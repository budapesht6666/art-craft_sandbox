# Шот «DON'T LOOK.»: позы Gemini, оживлённые в EffectCraft

- **Дата:** 2026-10-27
- **Программы:** EffectCraft 0.17.0 (сборка из кода, рендер), Pillow (подготовка фигур)
- **Исходники:** фон и позы из [../gemini/](../gemini/README.md)
- **Статус:** v1 готов, ждёт оценки; без звука

## Задача

Проверить, оживает ли кадр из Gemini так, как принято в жанре «вся история X»: персонажи
не играют покадрово, а меняют позы, мимика идёт заменой рисунка, двигается камера.
Это не перекладка Флюка, где кот должен был играть телом: здесь от рисунков нужна только
смена поз.

## Что сделано

Шот 6 с, 24 к/с, 1920×1080:

| Время | Что происходит |
|---|---|
| 0–1,2 с | Воин хмуро стоит и дышит, Персей крадётся со щитом (подскок шага, покачивание), медленный наезд камеры |
| 1,2 с | Замена позы: Персей протягивает голову, зажмурившись («поп» сплющить-растянуть 0,25 с), рывок камеры |
| 1,6 с | Воин кричит, его трясёт; титр «DON'T LOOK.» влетает с отскоком |
| 2,6–3,4 с | Вспышка взгляда, камень поднимается по воину снизу вверх (поза-статуя поверх крика с Linear Wipe), тряска камеры |
| 4,6 с | Персей открывает глаза и торжествует, камера отъезжает |

Конвейер как у Флюка: `make_assets.py` готовит фигуры, `gen_shot.py` считает ключи в
JSON, `ec/build_shot.js` строит проект в EffectCraft, CLI рендерит.

## Файлы

| Файл | Что это |
|---|---|
| `make_assets.py` | Фигуры из `gemini/cut/`: тон заката (228, 200, 182), тень под ногами, точка опоры у ступней → `ec/assets/` |
| `gen_shot.py` | Тайминг, шаги, поп, дрожь, камера → `ec/shot_keys.json` |
| `ec/build_shot.js` | Сборщик Флюка плюс Linear Wipe, плашка-вспышка, титр с обводкой |
| `ec/shot.ecproj` | Проект EffectCraft, композиция `DONT_LOOK` |
| `out/dont_look_v1.mp4` | Ролик (только локально, mp4 в `.gitignore`) |
| `out/dont_look_v1_contact.jpg` | Каждый 6-й кадр, лист 4×6 |

Пересобрать: `python make_assets.py && python gen_shot.py`, в EffectCraft сохранить проект
в `ec/` и выполнить `build_shot.js` через `run_script`, затем
`effectcraft-cli render --project ec/shot.ecproj --comp DONT_LOOK --out out/dont_look_v1.mp4 --format h264`
(144 кадра за 8 с).

## Вывод

- Механика жанра собирается из кода за один проход: замена поз, поп, дрожь, вытеснение
  камнем, титр, камера. Позы 4 и 6 Gemini нарисовал одинакового размера и с одной точкой
  у ног, поэтому камень лёг без подгонки. Это стоит просить и дальше: «same pose, same
  size» для пар «до/после».
- Слабые места v1:
  - нет звука: крик, хруст камня, вспышка и голос за кадром решают половину шутки;
  - вспышка на 45 % желтит весь кадр, лучше 20–25 % или только вокруг головы Медузы;
  - на фоне всё ещё статуи обычных пропорций (ждём фон v2 без статуй);
  - пауза 3,4–4,6 с длинная без голоса; под озвучку тайминг будет другим.
- Следующий шаг: фон v2, звук и голос, затем сцена подлиннее из листа 3.
