# Тест стиля: кадры «вся история X» кодом

- **Дата:** 2026-10-26
- **Программы:** VectorCraft 0.17.0 (рендер SVG в PNG); Python 3.12 (numpy, Pillow, scipy)
- **Статус:** готово, ждёт оценки пользователя

## Задача

Перед запуском канала «вся история / весь миф X за N минут» ([kb/youtube-research.md](../../kb/youtube-research.md),
раздел «Решение») проверить главный риск: дотягивает ли рисунок кодом до лидеров ниши,
Historically и Unknown Frequencies. Два кадра: карта и сцена с персонажами. Стоимость $0,
без генерации.

## Что сделано

1. Эталонные кадры сняты из роликов через Chrome (в `ref/`, только локально, чужие).
2. `geo.py` — береговая линия Natural Earth из пакета `world-atlas` (TopoJSON, 10 м),
   проекция, обрезка по кадру.
3. `frame_map.py` → `svg/map_troy.svg`: «A THOUSAND SHIPS». Греция и Троада цветом,
   «толщина» суши, мелководье, флот из 25 кораблей с пунктиром пути, Троя-крепость,
   армия из точек с мечами.
4. `frame_scene.py` → `svg/scene_perseus.svg`: «DON'T LOOK.» Персей зажмурился и
   держит голову Медузы, воин напротив каменеет снизу вверх, на фоне окаменевшие гости.
5. VectorCraft: `open_file` → `export` PNG 1920×1080 (`out/*_flat.png`).
6. `handmade.py`: дрожание линий, зерно бумаги, виньетка → `out/map_troy.jpg`,
   `out/scene_perseus.jpg`.
7. Лист сравнения с эталонами — `out/compare_local.png` (только локально: в нём чужие кадры).

## Вывод

- **Карта — проходит.** По приёмам это уровень Historically: «толщина» суши, армии из
  точек, крепость, корабли, подписи. Отличия: у эталона крупнее план и проще берег, у нас
  много мелких островов. Лечится масштабом и сильнее упрощённой линией.
- **Персонажи — проходят для старта, но не дотягивают до Unknown Frequencies.** Гэг
  читается сразу, человечки в духе жанра. Слабее эталона: фон плоский, без фактуры и
  глубины (у эталона прорисованная пещера со светом), линия одной толщины, мало деталей
  на персонажах. До «картонного кота» из прошлых проб далеко: здесь жанр прощает простоту.
- `handmade.py` заметно убирает «векторную стерильность».
- Время: карта ~20 минут, сцена ~30 минут работы вместе с правками. Персонажи, корабли,
  мечи, крепость — функции, их можно переиспользовать.
- Слабое место для конвейера — **фоны сцен**. Варианты: упрощённые фоны кодом с фактурой,
  картины общественного достояния, генерация фонов (Gemini бесплатно) с потерей «No AI».
