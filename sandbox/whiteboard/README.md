# Вайтборд: прорисовка сцены под голос

- **Дата:** 2026-10-25
- **Программы:** EffectCraft 0.17.0; Python 3.12 (numpy, Pillow, scipy); edge-tts 7.3.1;
  ElevenLabs API (`eleven_multilingual_v2`)
- **Статус:** готово

Папка называется `whiteboard`, а не `effectcraft-whiteboard`, потому что её завели до
правила об именах. Не переименовывать: пути к ассетам в `whiteboard.ecproj` абсолютные.

## Задача

Повторить стиль вайтборд-ролика: элементы прорисовываются с нуля под закадровый голос.
Исходник — три кадра одной сцены из ролика Whiteboard Crypto (лежат в
`whiteboard-crypto_test/`, в git не попадают). Это только проверка программ, публиковать
результат нельзя.

## Что сделано

1. `build_assets.py <папка с кадрами>` — нарезка кадров на 22 элемента (цвет и контур)
   и чистый фон в `assets/`.
2. Сборка в EffectCraft через `run_script`: по слою на элемент, Linear Wipe 100 → 0.
   Картинки — сначала контур, потом цвет. Текст — слева направо.
3. Субтитры ролика скачаны скиллом `youtube-transcript`. Кусок 0:57–1:30 вычищен вручную
   и записан в `voice.py` с метками `{элемент}`.
4. Две озвучки с привязкой элементов к словам:
   - `voice.py` — edge-tts, Дмитрий, бесплатно. Получились `voice.mp3` и `timing.json`;
   - `voice_eleven.py` — ElevenLabs, Daniel, ключ из `remotion-skill/.env`. Получились
     `voice_eleven.mp3` и `timing_eleven.json`. Ушло 447 символов квоты. Громкость
     подогнана под версию edge-tts усилением +3,6 дБ, исходник лежит в
     `voice_eleven_raw.mp3`.

5. **v2: перо и обработка голоса** (VectorCraft 0.17.0, SoundCraft 0.13.1):
   - VectorCraft трассирует контур каждого элемента по центральной линии
     (`imageTrace.makeAndExpand`, `strokes: true`, `fills: false`). Все 22 элемента
     одним `command_batch` → `assets/trace/*.svg`;
   - `sort_strokes.py` режет составные пути на отдельные штрихи и упорядочивает их: текст
     слева направо, рисунки сверху вниз;
   - EffectCraft: скрипт читает SVG с диска и вставляет его через
     `app.run("edit.pasteSvg")`. Штрихи утолщаются, добавляется Trim Paths
     (Individually), слой становится альфа-маской для картинки элемента. Надписи
     пишутся пером, у рисунков пером ведётся контур, потом проявляется цвет;
   - SoundCraft: голос ElevenLabs через срез низа 85 Гц, +2,5 дБ на 3,2 кГц,
     де-эссер, компрессор 3:1, Maximizer → `voice_v2.wav`, −16,4 LUFS. Сессия:
     `voice_v2.scsession`.

## Вывод

- Прорисовка и синхрон по словам работают. Расхождение начала элемента со словом
  не больше 0,15 с (проверено `silencedetect`).
- Громкость: −17,2 LUFS у версии edge-tts и −16,8 LUFS у версии ElevenLabs. Рендер
  EffectCraft поднимает звук примерно на 2,8 LU относительно исходного mp3.
- Какой голос лучше, решает пользователь на слух.
- v2: перо по контурам работает. Цена — рендер в 8 раз дольше (214 с против 25 с) и
  проект на 26 МБ.
- Во всех версиях есть статичные паузы по 2–4,6 с (по `freezedetect`): голос говорит, а
  на доске ничего не происходит (после «!» и после креста). Это вопрос раскадровки, а не
  программ.

Подробности и ловушки в [kb/whiteboard.md](../../kb/whiteboard.md).
