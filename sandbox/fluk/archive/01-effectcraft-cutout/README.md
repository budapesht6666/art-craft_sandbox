# Пилот: Fluk — The Cucumber

- **Дата:** 2026-10-26
- **Программы:** EffectCraft 0.17.0 (перекладка, рендер), SoundCraft 0.13.1 (мастеринг
  звука), VectorCraft 0.17.0 (просмотр и экспорт листа), Python 3.12 (персонаж, реквизит,
  синтез звука)
- **Статус:** v1 готова, качество не устроило

## Задача

Проверить, тянет ли наш конвейер персонажную анимацию: мульт-пантомиму без слов в духе
«Кота Саймона», бесплатно, без ИИ-видео. Почему выбран такой пилот, написано в
[kb/youtube-research.md](../../kb/youtube-research.md). Кот — **Флюк (Fluk)**, по фото
пользователя.

## Раскадровка (40 с, 1920×1080, 30 к/с)

| Время | Что происходит | Звук |
|---|---|---|
| 0–9 с | Флюк ест с закрытыми глазами; рука ступеньками спускается сверху и кладёт огурец за ним | хруст, крадущееся пиццикато, стук огурца |
| 9–16 с | Поднимает голову, мурчит, «ну и?», дёргает ухом, взгляд вправо, прищур, поворот головы | мурчание |
| 16 с | «Что?!»: зрачки-точки, уши прижаты, хвост распушён, наезд камеры | музыкальный удар |
| 16,6–17,7 с | Замах, прыжок по дуге в левый угол, приземление со сплющиванием, тряска камеры | свисток, удар |
| 18–26 с | Напряжение, подозрение, обвиняющий взгляд в камеру | тиканье часов |
| 26–31 с | Рука возвращается и кладёт огурец в его миску | пиццикато, «дзынь» |
| 31–37 с | Долгий взгляд на миску, потом в камеру, потом обиженно отворачивается | сверчок, свист хвоста |
| 37–40 с | Титр «Fluk — Episode 1: The Cucumber» | короткий джингл |

## Как сделано

1. **Персонаж.** `make_cat.py` рисует Флюка в SVG по частям на общем холсте 1000×1000
   (`parts/rig/`): хвост, тело, лапы, уши, голова, усы, нос, четыре рта, белки, маски,
   радужки, зрачки и пять положений века на каждый глаз. Лист эмоций —
   `out/sheet_v1.png`.
2. **Реквизит.** `make_scene.py` рисует фон-кухню, миску на подставке, огурец, руку и
   тень (`parts/scene/`).
3. **Сборка.** `build_scene.js` выполняется в EffectCraft через MCP `run_script`
   (`eval` файла, см. шапку скрипта):
   - каждая часть вставляется `edit.pasteSvg` векторным слоем-фигурой;
   - риг: null `cam` → null `cat_root` (точка у лап, масштаб 75%) → null `head_rig`
     (шея) → уши, глаза, рот. Зрачок привязан к радужке;
   - радужка и зрачок обрезаются альфа-маской по слою `matte_*`, одна маска на два слоя;
   - веки и рты меняются заменой: ключи прозрачности с интерполяцией HOLD;
   - взгляд, повороты головы, уши, рука сглажены easy ease (`KeyframeEase(0, 55)`);
     дуга прыжка — семь линейных ключей по параболе;
   - хвост качается выражением, при испуге и в финале — быстрее и сильнее;
   - надпись FLUK и титры — текстовые слои (SVG-текст `pasteSvg` не вставляет).
4. **Звук.** `sfx.py` синтезирует все эффекты (Карплус — Стронг для пиццикато, шумы,
   синусы) точно по таймингу → `fluk_sfx.wav`, −21 LUFS. SoundCraft: компрессор 3:1 от
   −26 дБ и Maximizer (порог −13, потолок −1,5) → `fluk_sfx_master.wav`, −16,8 LUFS.
   Сессия: `fluk_sfx.scsession`.
5. **Рендер.** `effectcraft-cli render --format h264 --audio on`: 1200 кадров за 74 с,
   итог −16,8 LUFS.

## Вывод

- **Технически** перекладка в EffectCraft работает и делается целиком из кода: риг,
  маски, замены, сглаживание, выражения, камера. Рендер совпадает с превью.
- **По качеству — провал**, оценка пользователя: «получилось дерьмо, ожидал большего».
  До «Кота Саймона» очень далеко: двигаются только голова и глаза, тело неподвижно,
  детали жёсткие, как у картонной куклы, вид анфас, линия стерильная, тайминг
  компьютерный, звук синтетический. Разбор в [kb/youtube-research.md](../../kb/youtube-research.md).
- Стоимость $0: ни одной генерации, весь звук свой.
- На эпизод ушло около двух часов вместе с отладкой рига. Следующие эпизоды быстрее:
  риг и звуковые функции готовы, нужны новые ключи и реквизит.
- Слабые места v1:
  - кот только в одной позе: сидит анфас. Для ходьбы, профиля и вида со спины нужны
    отдельные риги;
  - лап как отдельных конечностей нет: кот не может тянуться лапой;
  - синтезированные звуки простоваты, живое мяуканье и мурчание лучше записать.
