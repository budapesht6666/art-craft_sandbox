# Флюк: рисунок Gemini на сетке, кости в Blender

- **Дата:** 2026-10-26
- **Программы:** Blender 5.2.3 (EEVEE), рисунок из [gemini-fluk-art](../gemini-fluk-art/)
- **Статус:** технология подтверждена, ждём лист 4 (части тела)

## Задача

Анимировать рисунки Gemini без трассировки в вектор: натянуть картинку на сетку и гнуть
сетку костями, как в Live2D или Spine. Так сохраняется всё качество рисунка.

## Что сделано

`mesh_test.py` (запуск: `blender -b --factory-startup --python-exit-code 1 -P mesh_test.py -- OUT_DIR`):

1. Спрайт `pose_05.png` (сидящий Флюк, 544×584) → сетка 60×60 с UV, плоскость XZ,
   100 px на единицу.
2. Материал: Image Texture (Cubic) → Emission, альфа → Mix с Transparent,
   `surface_render_method = "BLENDED"`.
3. Кости (тело, голова, хвост из двух звеньев) в координатах пикселей спрайта,
   `align_roll((0, -1, 0))`: локальная ось Z смотрит в камеру, поэтому поворот вокруг Z
   идёт в плоскости рисунка.
4. Веса: `1/(d + 0.05)^4` по расстоянию до отрезков костей, модификатор Armature.
5. Поза: тело −6°, голова +14°, хвост −25° и −40°.

## Вывод

- **Работает:** рисунок гнётся плавно, линии и цвета не портятся
  (`out/mesh_rest_vs_posed.png`).
- **Части, перекрытые на исходнике, нужно рисовать отдельно.** Хвост лежал поверх тела,
  при взмахе под ним открылась «дыра» без контура. Поэтому заказан лист 4 с
  отдельными частями: торс, голова, лапы, хвосты.

## Ловушка

`bmesh.ops.create_grid(..., calc_uvs=True)` пишет UV только в **уже существующий** слой.
Без `bm.loops.layers.uv.new()` все UV нулевые: сетка берёт один угловой пиксель и
становится прозрачной.
