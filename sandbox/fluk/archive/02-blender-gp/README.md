# Fluk — Episode 0: The Red Dot (Blender + Grease Pencil)

- **Дата:** 2026-10-26
- **Программы:** Blender 5.2.3 LTS (Grease Pencil v3, EEVEE), Python 3.12 (синтез и
  сведение звука), ffmpeg
- **Статус:** v3 (Episode 1) готова, ждёт отзыва

## Задача

Пилот в EffectCraft ([effectcraft-cat-pilot](../effectcraft-cat-pilot/)) не устроил по
качеству: «картонная кукла». Цель — уровень хорошего инди-мультика, рисует Claude кодом.
Проверить, даёт ли это Blender: рисунок, который гнётся, а не двигается жёсткими
деталями.

- **v1** (белый фон, голова в профиль): пользователь согласился, что направление верное.
- **v2:** морда похожа на фото-референс, цветная комната, финал, титр, живые голоса.

## Как сделано

`fluk2d.py` запускается Blender без окна:

```
blender -b --factory-startup --python-exit-code 1 -P fluk2d.py -- [--stills 1,60,98] [--out DIR]
```

1. **Рисунок** — контрольные точки → кривые Катмулла — Рома. Лапы и хвост — «трубки»
   с переменной толщиной, открытые сверху. Тело в профиль, **голова в 3/4** по фото:
   широкая, с бакенбардами, крупный круглый розовый нос, тяжёлые веки, серо-зелёные
   глаза, наклон головы в покое.
2. **Риг считается в Python, в 2D:** кости, аналитический IK для лап (лапа стоит на полу,
   суставы сгибаются сами, при нехватке длины кости тянутся), кожа с весами `1/d⁴`.
3. **Анимация** — ключи по каналам с easy ease, хвост запаздывает по звеньям, глаза и
   взгляд (`cam`, `right`, `left`) меняются заменой. Камера с ключами: наезд в финале.
4. **Каждый рисунок — отдельный кадр Grease Pencil:** по двойкам, прыжок и финальный
   испуг по единицам. Noise с шагом 2 — «дрожание» линии и у кота, и у комнаты.
5. **Комната** — отдельный объект Grease Pencil: обои в полоску, пол с досками, синий
   ковёр (на красном точку не видно), окно со шторами и облаком, картина с рыбкой,
   диван, цветок.
6. **Звук** — `sfx_test.py`: синтез движений и живые голоса кота CC0 (см. ниже),
   ffmpeg `loudnorm` до −16 LUFS. Титр — ffmpeg `drawtext`.

## v3: милый Флюк и «Огурец» (Episode 1)

Отзыв на v2: «морда уродская и невыразительная, хочется милоты». Голова перерисована по
«детской схеме»: большая и круглая, глаза крупные, низко и широко, огромные зрачки с
двумя бликами, крошечный нос и рот «ω», розовые щёки, пухлые лапы, пушистый хвост.
Прищур с фото остался выражением `half` для смешных моментов. Лист выражений —
`out/fluk_expressions_v1.png` (`sheet.py`).

Код разделён:
- `fluk_rig.py` — модуль: персонаж, кости, IK, **ходьба** (фаза по пройденному пути,
  боковая схема шага), **разворот** (`flip`), глаза (`cute`, `hunt`, `wide`, `half`,
  `squint`, `closed`) и взгляд, рот (`cat`, `open`, `flat`, `smile`), распушённый
  хвост, комната, реквизит (огурец, миска, рука), сборка в Blender;
- `ep01_cucumber.py` — раскадровка серии;
- `sfx_ep01.py` — звук серии (синтез + живые записи CC0).

**«Fluk — Episode 1: The Cucumber»** — `out/fluk_ep01_cucumber.mp4`, 27,5 с + титр,
−16,4 LUFS. Флюк ест → рука на цыпочках кладёт огурец за ним → довольный, мурчит, милый
взгляд в камеру → оборачивается → крупный план «Что?!» → прыжок с выгнутой спиной и
распушённым хвостом → разворот → крадётся к огурцу → нюхает → тычет лапой, огурец
откатывается → крупный план «ну и?» → гордо уходит с хвостом трубой → огурец катится
следом → Флюк удирает из кадра. Рендер 660 кадров — около 8 минут.

Известное: прищур `squint` издалека читается как закрытые глаза, веко лучше поднять.

## Ловушки Blender 5.2 (проверено на 5.2.3)

- **Заливка рисуется только у штрихов с ненулевым `fill_id`.** У штриха, созданного из
  Python (`drawing.add_strokes`), `fill_id = 0`, и заливки нет. Ставьте каждому штриху
  свой номер, иначе соседние заливки сольются.
- **`layer.use_lights = False`**, иначе заливка темнеет.
- `material.grease_pencil.show_fill` / `show_stroke` из Python ненадёжны. У материала без заливки ставьте `fill_color = (0, 0, 0, 0)`, иначе открытый штрих зальётся чёрным.
- Цвета материалов линейные: sRGB → `c ** 2.2`, `view_transform = "Standard"`.
- После записи точек вызывайте `drawing.tag_positions_changed()`. Движок рендера только
  `BLENDER_EEVEE`.

Рецепт целиком — скилл `blender-2d` в `shared-claude-skills`.
