# EffectCraft: первая проверка MCP

**Дата:** 2026-10-25. **Программа:** EffectCraft 0.17.0. **Статус:** готово.

## Задача

Проверить, что Claude может собрать анимацию в EffectCraft через MCP и выгрузить её
файлом.

## Что сделано

1. Через MCP без окна (`run_script`, модель объектов After Effects) создана композиция
   Plate: 1080×1920, 30 кадров в секунду, 3 секунды.
2. Текстовый слой «ПОДПИШИСЬ» выезжает снизу (0 → 0,6 с) и проявляется (0 → 0,4 с).
3. Экспорт в Lottie (`file.exportLottie`), сохранение проекта (`save_project`).
4. Кадр на 1 с отрендерен через `effectcraft-cli render-frame`.
5. Проект открыт в окне программы через `effectcraft-app` (канал управления на
   порту 9877): ползунок времени и скриншот работают.

## Файлы

| Файл | Что это |
|---|---|
| `plate.ecproj` | Проект EffectCraft. Открывается через File → Open |
| `plate.json` | Экспорт в Lottie (954 байта) |
| `frame.png` | Кадр на 1 с, 360×640 |

## Вывод

Вся цепочка работает: сцена, ключевые кадры, Lottie, рендер, живое окно. Кириллица
отображается нормально.

Не проверено: как этот Lottie воспроизводится в Remotion. Текст в Lottie хранится как
имя шрифта (Inter), а не как форма букв.
