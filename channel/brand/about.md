# Тексты канала для YouTube Studio

Всё на английском: канал для США. Переводы описания — на языки наших субтитров
(Studio → Настройка канала → Описание канала → «Добавить перевод»).

## Описание канала (EN, ~700 знаков из 1000)

```
History is weird. We tell you the whole thing. Pretty much.

Hi, I'm Barnaby the Bard. I've been telling stories since before writing was cool. Here I tell the ENTIRE story of myths, heroes, gods, empires and the people who messed them all up: start to finish, in one cartoon, with jokes.

Greek myths, ancient kingdoms, legendary heroes and a lot of terrible decisions. Mostly accurate. Always ridiculous.

Subtitles: English, Español, Português, Deutsch, Français, हिन्दी.

Subscribe, and I'll tell you how it really happened. Pretty much.
```

## Ключевые слова канала

Studio → Настройки → Канал → Основная информация → Ключевые слова:

```
history, mythology, greek mythology, animated history, history cartoon, mythology explained, ancient history, entire story, myths and legends, ancient greece, roman empire, funny history
```

## Прочие поля

| Поле | Что ставить |
|---|---|
| Местоимения | пусто |
| Логотип канала | `out/watermark.png`, показ «Всё видео» |
| Аудитория (Настройки → Канал → Расширенные) | «Нет, канал не для детей» |
| Страна | та, где будет AdSense для выплат |
| Загрузка по умолчанию → Категория | Education |
| Загрузка по умолчанию → Язык видео и субтитров | English |
