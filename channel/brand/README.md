# Оформление канала Pretty Much History

- **Дата:** 2026-10-27
- **Программы:** Gemini API (`gemini-nano-banana-2.1`), Pillow
- **Статус:** название, псевдоним и аватар выбраны; канал на YouTube ещё не создан

## Решения (пользователь, 2026-10-27)

| Что | Решение |
|---|---|
| Название канала | **Pretty Much History** |
| Хэндл | `@PrettyMuchHistory` (свободен на 2026-10-27, проверка: `youtube.com/@<хэндл>` отдаёт 404) |
| Ведущий (голос за кадром, персонаж на аватаре) | **Barnaby the Bard**: бродячий рассказчик-всезнайка, лавровый венок набекрень, лира |
| Аватар | портрет ведущего (не значок) |

Отвергнутые варианты названия: Mostly Ancient, Myths, Roughly, The Grumpy Oracle (их хэндлы тоже
были свободны). Из очевидных занято: AncientNonsense, OddlyAncient, TotallyEpic, RoughlyHistory,
TheWholeMyth, HistoryExplainedBadly и др.

## Что сделано

1. [gen_brand.py](gen_brand.py) — задания Gemini для оформления. Библия каста и ключ берутся из
   генератора серии `../episodes/01-perseus/art/gen.py`, эталон стиля — лист каста Персея.
2. `out/barnaby_model.png` — лист Барнаби в полный рост: нейтрально, «well, technically», пожатие
   плечами «eh, pretty much», поёт с лирой. Эталон ведущего для будущих серий.
3. Три аватара по листу: `out/avatar_a|b|c.png` (2K) и `_800.png` для загрузки (800×800, ~0,5 МБ):
   - **a** — ухмылка, лира, жёлтый фон: туника сливается с фоном;
   - **b** — палец вверх «сейчас расскажу», терракотовый фон: самый заметный в ленте;
   - **c** — пожимает плечами, бирюзовый фон: жест прямо про название «pretty much».
4. Лист сравнения кругом на 360/88/48/36 px на тёмном фоне YouTube: `local/compare.png`
   (собирает `local/compare.py`).

5. **Баннер** `out/banner.jpg` (2560×1440, 1 МБ; PNG 5,7 МБ у предела 6 МБ): фон Gemini
   `banner_bg` (панорама: пирамиды, Парфенон, Колизей, драккар, Великая стена, замок) + Барнаби с
   пальцем вверх + надписи шрифтом Luckiest Guy (`fonts/`, Apache 2.0). Собирает [compose.py](compose.py),
   кегль подгоняется под зону телефона 1546×423. Разметка зон: `local/banner_zones.png`.
6. **Логотип в плеере** `out/watermark.png` — аватар c кругом, 150×150, прозрачный фон.
7. **Тексты** для Studio: [about.md](about.md) (описание EN + 5 переводов, ключевые слова, поля).

Стоимость: 5 вызовов Gemini, ≈ $0,25.

Ловушка: первая сборка баннера с кеглем «на глаз» вылезла за зону телефона (обрезалось бы
«HISTORY»). Кегль теперь считается от ширины зоны.
